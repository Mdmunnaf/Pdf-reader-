# FitPDF

PDF reader যেখানে পেজের উপরে-নিচে-পাশে কোনো ফাঁকা জায়গা থাকে না। অ্যাপ নিজে প্রতিটি পেজ স্ক্যান করে লেখার সীমানা খুঁজে বের করে, বাকি সাদা অংশ কেটে ফেলে, আর পেজগুলো একটার পর একটা জোড়া লাগিয়ে দেখায়।

## Features
- **Auto Trim**: প্রতি পেজের উপর-নিচের ফাঁকা অংশ বাদ। বাম-ডানের মার্জিন পুরো ডকুমেন্টে একই থাকে, তাই লাইন এলোমেলো হয় না।
- **Full-screen**: পড়ার সময় status bar ও navigation bar লুকানো থাকে। স্ক্রিনে ট্যাপ করলে কন্ট্রোল আসে।
- সম্পূর্ণ ফাঁকা পেজ নিজে থেকে স্কিপ।
- Night mode (রং উল্টে দেয়), Zoom 1× / 1.5× / 2× / 3×।
- ফাইল ম্যানেজার, ব্রাউজার বা চ্যাট অ্যাপ থেকে "Open with → FitPDF"।
- বাংলা ও ইংরেজি UI।
- কোনো থার্ড-পার্টি PDF লাইব্রেরি নেই, Android-এর নিজস্ব `PdfRenderer` ব্যবহার হয়েছে।

## GitHub দিয়ে APK বানানো
1. GitHub এ নতুন repository খুলুন এবং এই ফোল্ডারের সব ফাইল push করুন (`.github` ফোল্ডারসহ)।
2. **Actions** ট্যাবে `Build APK` চলবে। শেষ হলে run-এর নিচে **Artifacts → FitPDF-apk** থেকে APK নামান।
3. Release পাবলিশ করতে একটি tag push করুন:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   তাহলে **Releases** পেজে `FitPDF.apk` নিজে থেকে যুক্ত হবে।

## নিজের কম্পিউটারে বানাতে
Android Studio-তে ফোল্ডারটি Open করুন, অথবা JDK 17 ও Gradle 8.7 থাকলে:
```bash
gradle assembleDebug
```

## কাস্টমাইজ
`PdfEngine.kt` এর উপরের ধ্রুবকগুলো:
- `PAD_X`, `PAD_Y`: কনটেন্টের চারপাশে কতটুকু নিরাপদ ফাঁকা রাখা হবে।
- `INK_THRESHOLD`: কত হালকা রঙকে "সাদা" ধরা হবে।
